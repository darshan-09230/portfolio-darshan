Selected Projects

Algal Bloom Reduction System

An environmental engineering project investigating technology-based approaches to reducing algal blooms in local lakes.It uses ML to predict algal bloom and then accordingly uses ion exchange membranes and electric charges to reduce nutrients that lead to algal growth.

HandSync

An embedded machine-learning system using a Gyroaccelerometer and microcontroller to capture and classify hand movements. It uses a convolutional neural network trained on approximately a 1000 samples and can classify between between A,B,C,D,E with 86% accuracy. The ai model runs locally on the microcontroller and attempts to test the limits of gesture classification with cheap hardware.

LinkBot

A machine-learning Discord bot that categorizes digital tools using TF-IDF and SVM classification. It was trained on over scraped data of 1700 websites. It categorizes digital tools into niche categories and uploads them on a discord server so people can use these tools without having to spend time finding tools that you need.
